# H → ZZ* → 4ℓ 项目的物理原理

> **适用范围：** 本文解释本项目背后的物理逻辑，重点回答“数据从哪里来、为什么选择
> 四轻子、XGBoost 在做什么，以及为什么必须检查质量塑形”。具体数据文件见
> [数据说明](data-description.md)，逐条 selection 定义见
> [事件选择标准](selection-standard.md)。

## 1. 项目研究的问题

本项目研究的信号过程是：

\[
pp\rightarrow H\rightarrow ZZ^*\rightarrow4\ell,
\qquad \ell=e,\mu.
\]

两个高能质子在 LHC 中对撞。质子内部的夸克和胶子发生硬散射，其中胶子融合可以产生
Higgs 玻色子。Higgs 随后衰变成两个 Z 玻色子，Z 再衰变为电子或 muon：

\[
Z\rightarrow e^+e^- \quad\text{或}\quad Z\rightarrow\mu^+\mu^-.
\]

因为 Higgs 质量约为 125 GeV，小于两个在壳 Z 玻色子的质量之和
\(2m_Z\approx182.4\) GeV，所以通常至少有一个 Z 不在质量壳上，记为 \(Z^*\)。这也是
第二个轻子对的质量可以明显低于 91.2 GeV 的原因。

四轻子末态常被称为 Higgs 的“黄金道”：分支比不大，但电子和 muon 可以被较精确地
重建，四轻子不变质量也具有较好的分辨率。

## 2. 从对撞到项目表格

数据产生过程可以概括为：

```text
质子—质子对撞
  → 产生 Higgs、ZZ 或其他物理过程
  → 不稳定粒子衰变
  → 电子和 muon 穿过 ATLAS 探测器
  → 探测器记录径迹、能量沉积和 muon 信号
  → 重建算法形成 lepton 候选
  → 触发和上游 skim 保留可能有用的事件
  → ROOT ntuple
  → 本项目 selection、四动量重建和特征计算
  → MC 训练表或封存的真实数据表
```

因此，ROOT 文件中的一个轻子不是“物理定律直接给出的粒子”，而是探测器信号经过
校准、重建和鉴别后得到的候选。selection 的一部分作用，就是只保留探测器能够较可靠
测量的候选。

## 3. 四动量与不变质量

粒子的四动量写成：

\[
p^\mu=(E,\vec p).
\]

若将若干粒子的四动量相加，总体系的不变质量为：

\[
m^2=\left(\sum_i E_i\right)^2-
\left|\sum_i\vec p_i\right|^2.
\]

本项目最重要的质量变量是：

- \(m_{\ell\ell}\)：一个轻子对的不变质量；
- \(m_{Z1}\)：最接近名义 Z 质量的同味异号轻子对质量；
- \(m_{Z2}\)：剩余同味异号轻子对质量；
- \(m_{4\ell}\)：四个轻子合成体系的不变质量。

如果四个轻子来自一个 Higgs 衰变，它们的总四动量近似等于母粒子 Higgs 的四动量，
所以 \(m_{4\ell}\) 会集中在约 125 GeV。实验图上的峰宽主要受到探测器分辨率、辐射和
重建效应影响，不能直接理解为 Higgs 的自然宽度。

## 4. 为什么连续 ZZ 是背景

标准模型不经过 Higgs 共振也可以直接产生：

\[
pp\rightarrow ZZ^{(*)}\rightarrow4\ell.
\]

它与 Higgs 信号具有相同的可见末态：都是四个电子或 muon。逐个事件只看最终粒子，
通常无法确定它来自 Higgs 还是连续 ZZ，因此连续 ZZ 是**不可约背景**。

二者的主要区别是：

- Higgs 是质量约 125 GeV 的共振，信号 \(m_{4\ell}\) 呈窄集中；
- 连续 ZZ 不经过 125 GeV Higgs 共振，\(m_{4\ell}\) 通常形成较平滑的连续谱；
- 两者的角分布、Z 候选质量和整体运动学也存在统计差异。

“背景”不等于错误或无物理意义。ZZ 是真实存在的标准模型过程，只是对于寻找 Higgs
这一目标而言，它会产生相同末态，因此被归入背景类别。

真实分析中还可能存在 \(Z+\)jets、\(t\bar t\) 等可约背景，其中 jet 或非 prompt
lepton 被误识别为信号轻子。当前 Demo 主要研究 Higgs MC 与连续 ZZ MC 的区分，并未
完成正式分析所需的全部背景估计。

## 5. 常用运动学量

### 5.1 横向动量 \(p_T\)

\(p_T\) 是垂直于质子束流方向的动量。质子内部 parton 沿束流方向的初始动量未知，
而初态总横向动量通常较小，所以横向量更适合在强子对撞机中比较。

设置最低 \(p_T\) 的原因包括：

- 过软轻子更难触发和可靠重建；
- 低 \(p_T\) 区域的识别效率和背景污染通常更不稳定；
- Higgs 四轻子事件仍可能包含来自离壳 \(Z^*\) 的较软轻子，因此门槛不能全部设得过高。

### 5.2 赝快度 \(\eta\)

赝快度定义为：

\[
\eta=-\ln\tan\frac{\theta}{2},
\]

其中 \(\theta\) 是相对束流轴的极角。\(|\eta|\) 越大，粒子越靠近束流方向。电子和
muon 的 \(|\eta|\) 接受度不同，是因为它们主要依赖不同的探测器子系统。

### 5.3 方位角与角距离

\(\phi\) 是横向平面中的方位角。常用的角距离为：

\[
\Delta R=\sqrt{(\Delta\eta)^2+(\Delta\phi)^2}.
\]

它用于描述两个重建对象在探测器中的分离程度，也是隔离和角分布变量的基础。

## 6. Selection 的物理逻辑

事件选择不是为了逐事件“证明这是 Higgs”，而是定义一个可重建、可比较的四轻子分析
相空间。主要条件的作用如下：

| 条件 | 物理作用 |
|---|---|
| Trigger 与 trigger matching | 确认事件由适当的在线触发记录，并能与离线轻子对应 |
| Lepton identification | 排除不符合电子或 muon 探测器特征的候选 |
| Isolation | 抑制 jet 内部或重味强子衰变产生的非 prompt lepton |
| \(d_0/z_0\) impact parameter | 要求轻子与主要碰撞顶点相容 |
| 基础 \(p_T\) 与 \(\eta\) | 限制在探测器能够较可靠重建的接受区 |
| 四轻子总电荷为零 | 与两个中性 Z 玻色子各自衰变为异号轻子相符 |
| 两个不重叠 SFOS pair | 构造 \(e^+e^-\) 或 \(\mu^+\mu^-\) 的 Z 候选 |
| 所有 SFOS 质量下限 | 抑制低质量共振和不适合本分析的组合 |
| \(m_{Z1}\)、\(m_{Z2}\) 窗口 | 保留符合 \(ZZ^*\) 拓扑的候选 |
| 宽 \(m_{4\ell}\) 窗口 | 覆盖 125 GeV 附近及两侧区域，供后续形状检查 |

通过 selection 只表示事件符合分析条件。Higgs、连续 ZZ 和其他背景都可能通过同一套
selection；因此 selection 后仍需要统计模型来区分信号和背景。

## 7. Z1 和 Z2 是重建约定

在 \(4e\) 或 \(4\mu\) 事件中，四个轻子可能有多个合法的同味异号配对。本项目把质量
最接近 \(m_Z=91.1876\) GeV 的轻子对定义为 Z1，剩余一对定义为 Z2。

这是一个确定性的分析规则，不代表我们能够在量子层面逐事件知道哪个轻子来自“第一
个 Z”。配对规则必须在 MC 和真实数据上保持一致，才能进行可比的统计分析。

## 8. MC、真实数据和标签

### 8.1 Monte Carlo 模拟

MC 从指定的物理过程和生成器开始，模拟粒子产生、衰变、探测器响应和事件重建。因为
生成过程已知，本项目可以赋予标签：

- Higgs MC：信号，标签 `1`；
- 连续 ZZ MC：背景，标签 `0`。

MC 不是对真实碰撞的复制。它依赖理论计算、生成器、探测器模拟和校准，因此正式分析
还需要系统误差和数据控制区验证。

### 8.2 真实碰撞数据

真实数据中的事件没有“信号/背景真值标签”。项目中的 `-1` 只是程序用于标记无标签
数据的约定，不能把它作为第三种物理类别训练。

真实数据可以在模型、selection、工作点和统计程序全部冻结后用于最终检验，但不能反过来
参与调参，否则会把真实数据中的统计涨落带入分析选择。

## 9. 物理权重与训练权重

不同 MC 样本的生成事件数并不等于真实实验中预期看到的事件数。物理权重近似为：

\[
w_{\mathrm{phys}}
=\mathcal L
\frac{\sigma k\epsilon_{\mathrm{filter}}}{\sum w_{\mathrm{MC}}}
w_{\mathrm{MC}}.
\]

其中 \(\mathcal L\) 是积分亮度，\(\sigma\) 是截面，\(k\) 是高阶修正因子，
\(\epsilon_{\mathrm{filter}}\) 是生成过滤效率。带符号的物理权重用于计算预期产额。

部分 MC 事件可能有负生成器权重。这是高阶计算与事件生成匹配产生的数值贡献，不表示
“负事件”。由于 XGBoost 不接受负 sample weight，本项目训练时使用归一化的
\(|w_{\mathrm{phys}}|\)，而物理产额报告仍保留带符号权重。两者用途不能混淆。

## 10. XGBoost 在做什么

XGBoost 学习 MC 中 Higgs 与 ZZ 的多变量统计差异。每棵决策树根据运动学变量做一系列
切分，多棵树组合后给出一个分类分数：

```text
较高分数 → 在训练变量空间中更像 Higgs MC
较低分数 → 在训练变量空间中更像 ZZ MC
```

这个分数不是“事件来自 Higgs 的概率”，高分事件也仍可能是 ZZ 背景。只有将固定工作点
后的质量谱、背景模型、系统误差和统计检验结合起来，才能讨论信号证据。

本项目禁止把 \(m_{4\ell}\) 直接作为模型特征。如果允许模型直接读取质量，它只需学习
“接近 125 GeV 就给高分”，得到的高 AUC 没有独立的物理价值，也会破坏之后用质量谱
检验 Higgs 峰的逻辑。

## 11. 为什么不使用 m4l 仍会发生质量塑形

即使模型没有直接读取 \(m_{4\ell}\)，其他变量也可能与它相关，例如轻子 \(p_T\)、
Z 候选质量和四轻子整体运动学。模型通过这些相关变量仍可能间接推断质量区域。

对模型分数设置门槛后，背景接受效率可能随 \(m_{4\ell}\) 改变：

\[
\epsilon_{ZZ}(m_{4\ell})
=\frac{N_{ZZ}(\text{score通过},m_{4\ell})}
{N_{ZZ}(\text{selection通过},m_{4\ell})}.
\]

如果该效率在 125 GeV 附近异常升高，原本平滑的 ZZ 质量谱就可能被雕刻成类似峰的形状，
这称为**质量塑形**。训练时这些事件虽然仍被标为背景，但最终实验看到的是“通过分数
门槛后的数据质量谱”，而不是 MC 的 truth label。因此背景标签本身不能消除质量塑形。

本项目使用工作点前后 ZZ 的加权质量分布、加权 KS 距离和 score–mass 关系检查这个问题。
理想分类器需要在保持足够信号—背景区分能力的同时，使 ZZ 接受效率尽量不依赖质量。

## 12. Train、development、test 和真实数据

为避免把同一批统计涨落既用于选择又用于评价，数据角色必须分开：

| 数据部分 | 允许用途 | 禁止用途 |
|---|---|---|
| Train MC | 拟合模型参数 | 报告最终无偏性能 |
| Development/OOF MC | 选择候选模型、工作点和去相关策略 | 代替最终 test |
| Held-out MC test | 冻结后进行一次独立评价 | 调参或改变门槛 |
| 真实数据 | 在独立盲化协议批准后进行物理检验 | 监督训练、按结果回调模型 |

如果某个方案没有通过预先规定的 development 门槛，就不应因为“test 或真实数据看起来
不错”而放宽标准。否则最终结果会受到选择偏差影响。

## 13. 当前项目能够说明什么

当前项目能够展示：

- 如何从四轻子 ROOT ntuple 构造可审计的 MC 分析表；
- Higgs MC 的 \(m_{4\ell}\) 在约 125 GeV 集中；
- XGBoost 可以学习 Higgs MC 与连续 ZZ MC 的运动学差异；
- 分类能力与背景质量稳定性之间存在真实的权衡；
- 为什么在打开真实数据前必须冻结模型并检查质量塑形。

当前项目**不能**声称：

- 已在真实数据中发现 Higgs；
- 测量了 Higgs 质量、截面或显著性；
- 已包含完整背景、系统误差和正式 ATLAS 统计模型；
- 高分事件一定来自 Higgs。

正式的物理结论还需要更多数据 period、可约背景估计、控制区、系统误差、冻结后的
质量谱拟合和盲化检验。
