# DSID 363490 Enhanced-Selection Training Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Download ATLAS DSID 363490, adapt its 2020 `mini`/MeV format to the existing canonical event model, apply the approved trigger/ID/isolation/impact-parameter selection, retrain the MC-only classifier, show the 125 GeV Higgs MC peak, and evaluate the frozen model on DSID 700600 without using real data to tune anything.

**Architecture:** Add a small named input-profile layer before the existing selection so 2020 and Release-22 ROOT files produce identical canonical event dictionaries. Extend selection with an optional, fully configured lepton-quality block while preserving the legacy `demo.yaml` behavior. Keep preprocessing, training, plotting, and external validation in separate immutable run directories; the external 700600 command loads only a frozen model/working points and cannot call a fitting seam.

**Tech Stack:** Python 3.12, uproot 5, awkward 2, NumPy, pandas, PyYAML, scikit-learn, XGBoost 3, Matplotlib/mplhep, pytest.

## Global Constraints

- Preserve `config/demo.yaml`, `data/raw/zz.root`, every existing `runs/*` artifact, `data/processed/`, and `outputs/` byte-for-byte.
- Save the new download as `data/raw/zz_363490.root`; never use a partial file as input.
- DSID 363490 is background label `0`; Higgs 345060 is signal label `1`; real data is never used for fitting, threshold choice, or model comparison.
- `m4l`, identifiers, source/profile names, DSIDs, and all weights remain forbidden model features.
- Apply the same canonical enhanced selection to Higgs 345060, ZZ 363490, and external ZZ 700600.
- Use DSID 363490 normalization exactly as `xsec_pb=1.2564`, `k_factor=1.0`, `filter_efficiency=1.0`, `sum_of_weights=7538705.808`; do not silently apply the tutorial's factor `1.3`.
- Use trigger `trigE || trigM`, trigger matching, Tight ID, track/calo isolation `<0.3`, electron `|d0sig|<5`, muon `|d0sig|<3`, and `|z0*sin(theta)|<0.5 mm`.
- Retain ordered lepton thresholds `20,15,10,7 GeV`, electron `|eta|<2.47`, muon `|eta|<2.7`, SFOS/Z windows, and `105 <= m4l < 160 GeV`.
- Model candidates, tree count, and loose/medium/tight working points are selected only from development/OOF MC; independent test and external 700600 are read only after those choices freeze.
- Do not score or manually inspect real-data events in `120--130 GeV`.
- All production runs use fresh non-symlink run directories and manifest-last publication; failed run names are never deleted or reused.
- The parent repository currently treats the whole project as untracked. Do not stage or commit an isolated subset; use the per-task report checkpoints below until the user explicitly establishes project Git history.
