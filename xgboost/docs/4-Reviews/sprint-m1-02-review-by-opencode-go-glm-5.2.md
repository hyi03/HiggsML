## 1. Executive summary

Sprint M1-02 is the data-boundary sprint of the refactor: it migrates the pure domain functions (four-momentum, SFOS pairing, Z1/Z2, selection/cutflow, Base14/Angular5, weights, identity, split) and the MC-only ROOT preprocessing pipeline, and makes one `higgsml-preprocess` run publish physically separated development/test Angular19 datasets with a full manifest. The plan's scope, sequencing (TDD domain first, then reader/pipeline, then outputs/manifest, then CLI), and risk controls all match the approved design and the constraints accepted in the M1-01 review cycle.

Before execution, the following must be addressed:

1. **[H-1]** The central data contract of this sprint is not pinned. §6 requires the output to "恰好包含固定顺序的 19 项模型特征和必要 metadata", but "必要 metadata" is enumerated nowhere — not in the sprint, the FR, the design, or `preprocessing_protocol_v1.yaml`. Nor does the sprint state that `development.csv.gz` = train+validation rows with the per-row split-role column preserved. The current authority table carries `label`, `split`, `physical_weight`, `channelNumber`, `eventNumber`, and `m4l` (`src/experiment_runner.py:36-43`); M1-03 needs `m4l` in the development file for the ZZ KS gate while it must stay out of the model features. As written, the "恰好包含" acceptance criterion is not verifiable, and M1-03/M1-04 both bind to this schema.
2. **[H-2]** M1-01 §5.3 explicitly deferred input-replacement detection to "读取实际输入的 M1-02/M1-03 source-binding 测试" (`sprint-m1-01.md:100-102`). M1-02's task and test lists contain no input SHA-256/stat recording, no post-read revalidation, and no replaced-input rejection test — the design (§8.1 "每个 ROOT 输入在读取前后验证常规文件状态与内容记录"; §11 "被替换输入均被拒绝") and the protocol (`inputs.sha256_required: true`) both require them. M1-03's tamper tests target the upstream manifest, not the ROOT inputs, so if M1-02 omits this, the requirement falls through both sprints.
3. **[M-1..M-4]** The full-suite verification gate is undeclared given the recorded 211 legacy failures; design stage-3's "现有权威计数验证等价" is neither scheduled nor declared as an unexecuted boundary; the micro-ROOT fixture requirements are unspecified and the CLI smoke has no concrete command; the focused `-k "domain or preprocess"` run silently depends on test naming.
4. **[L-1..L-3, I-1..I-3]** §10 placeholder without the evidence checklist, untraceable "预注册等价政策" reference, and protocol-scope ambiguity.

No scientific-safety violation was found in the target document.
