# 中文项目报告：三种结构优化方案及目录对比

日期：2026-11-01

评阅对象：[当前中文项目报告](project-report-cn.tex)。本文只提出结构与排版方案，不修改正文、数值、图表或分析协议。依据为当前报告、draft-v2 README、工作流与补充统计评估说明；没有重新核验运行产物或执行科学分析。

## 一、当前结构为什么显得乱

当前顺序为：目标与进展 → 数据与事件结构 → 重建与输入 → 网络筛选与保留样本 → 质量谱 → 归一化谱形 → 项目状态与下一步 → 来源。

1. **两条主线没有分清主次。** 标题和开头承诺解释“筛选前后的质量谱”，但第 7 章又承担输入组比较、区间推断和统计评估，近似另一篇研究报告。
2. **方法与结果混排。** 第 4 章依次讲训练、阈值、物理权重、评估事件数和产额；读者难以辨认何处结束方法、何处开始结果。
3. **核心定义出现过晚。** 前文已提到 W68，但区间构造、高低分类别均进入似然、展示分箱与推断分箱的区别，到第 7 章才集中说明。
4. **章节职责与标题不匹配。** “项目状态与下一步”包含主要数值表、重抽样结果和欠覆盖信息，应拆成结果、统计诊断、结论与后续工作。
5. **细节层次不均衡。** ROOT 字段、完整选择来源对照和角度构造占据连续篇幅，而核心结果与限制挤在一章。详细资料应保留，但不必全部放在主阅读路径。
6. **分页主导内容组织。** 源码多处使用强制分页，部分续页没有独立的小节标题。新版应先建立章节层级，再围绕图表安排分页。本次判断来自源码，未重新渲染检查 PDF。

## 二、三个方案的总体比较

| 维度 | 方案一：质量谱专题型 | 方案二：完整研究论文型 | 方案三：问题驱动汇报型 |
|---|---|---|---|
| 核心问题 | 网络筛选怎样改变产额与质量谱？ | 不同输入组怎样影响标称区间宽度，证据有多稳健？ | 已回答哪些问题，还需要解决什么？ |
| 阅读顺序 | 对象 → 选择方法 → 产额 → 谱形 → 解释 | 问题 → 设计 → 方法 → 结果 → 诊断 → 讨论 | 问题与发现 → 最少背景 → 分问题展示证据 → 后续工作 |
| 适合读者 | 当前报告读者、希望理解物理选择的导师 | 系统评阅完整研究的读者 | 时间有限的导师、组会参与者 |
| 质量谱角色 | 正文中心 | 解释分类选择的辅助结果 | 一个独立问题的直接证据 |
| 区间结果角色 | 简短关联说明，完整资料置于附录 | 正文主要结果 | 独立问题章节 |
| 改动规模 | 中等，保留现有主题 | 较大，需要重写标题、引言和过渡 | 中等，需要重写章首问题与答案 |
| 主要取舍 | 对整个项目的统计结论展示较少 | 方法较密集，正文可能更长 | 查找集中方法细节需要翻附录 |

## 三、方案一：质量谱专题型（当前报告首选）

建议标题：**神经网络筛选对四轻子模拟样本产额与质量谱的影响**。

主线：先定义比较总体与选择方法，再依次回答“保留了多少”“保留在哪里”“形状发生什么变化”。

1. **研究问题与比较范围**
   - 1.1 为什么同时研究总产额和质量谱形
   - 1.2 “筛选前”与“筛选后”的定义
   - 1.3 ABCD、BCD 与种子 42 的展示范围
2. **模拟样本与共同事件选择**
   - 2.1 信号、背景与教育用途 MC 范围
   - 2.2 轻子选择、候选重建及质量窗口
   - 2.3 样本划分、事件计数与产额权重
3. **网络输入与冻结筛选方法**
   - 3.1 A/B/C/D 输入组与隐含质量信息
   - 3.2 训练、验证 AUC 与检查点选择
   - 3.3 验证背景阈值及最终评估规则
4. **筛选效果：事件数与预期产额**
   - 4.1 同一评估总体中的高分子集
   - 4.2 信号保留率与背景抑制
5. **质量谱变化及其解释**
   - 5.1 绝对产额谱：信号和背景位于哪里
   - 5.2 归一化谱形：去除总量变化后还剩什么差异
   - 5.3 固定质量区域占比与统计支持限制
6. **结论、研究关联与局限**
   - 6.1 对筛选与质量相关性的主要认识
   - 6.2 与标称区间研究的关联：高低分类别均参与推断
   - 6.3 当前证据边界与下一步

附录 A：读取字段、重建公式与角度约定。

附录 B：完整选择条件、文献来源与项目差异。

附录 C：区间构造、五种表示的结果及 bootstrap/model-self 诊断。

正文第 6 章应明确概括区间结果的探索性、非独立和欠覆盖限制，不能将影响解释的限制全部藏入附录。

建议篇幅分配：第 1—6 章分别约占正文的 10%、20%、20%、15%、25%、10%；参考文献和附录另计。两幅谱图集中在第 5 章，依次展示绝对量与归一化形状。

## 四、方案二：完整研究论文型

建议标题：**四轻子模拟样本中运动学输入组对神经网络分类与标称信号强度区间的影响**。

主线：围绕输入组比较组织完整论证，质量谱解释选择机制，统计诊断限定结果的可信程度。

1. **引言：研究问题与研究范围**
   - 1.1 物理背景与输入组比较的动机
   - 1.2 分类表现、质量谱与区间宽度的区别
   - 1.3 本研究能够回答的问题与范围
2. **模拟样本与实验设计**
   - 2.1 数据来源、共同选择与候选重建
   - 2.2 物理权重及 60/20/20 样本分工
   - 2.3 五种表示、三个种子与共享包容计数参考
3. **分析方法与评价指标**
   - 3.1 输入变量、网络训练和验证选择
   - 3.2 冻结阈值及高低分双类别
   - 3.3 T1 似然、Asimov 观测与 W68
   - 3.4 种子内删组差值及汇总规则
   - 3.5 配对 bootstrap、阈值诊断与 model-self Toys 方法
4. **结果**
   - 4.1 标称区间宽度与包容计数参考
   - 4.2 删去各输入组的配对差值
   - 4.3 产额与质量谱：解释示例模型的事件选择
5. **稳定性与区间覆盖诊断**
   - 5.1 种子变化与有限 MC 重抽样
   - 5.2 阈值重估对比较的影响
   - 5.3 模型自生成检验中的覆盖率与欠覆盖
6. **讨论与局限**
   - 6.1 输入组作用能够支持到什么程度
   - 6.2 隐含质量信息与单质量箱推断的边界
   - 6.3 非独立性、物理适用性与待验证事项
7. **结论与后续工作**

附录 A：字段、完整选择来源和重建约定。

附录 B：网络配置及完整候选/种子结果（只使用已有核验材料）。

附录 C：产物身份与复现说明。

建议篇幅分配：第 1—7 章约占正文的 10%、15%、25%、25%、10%、10%、5%。若总页数严格限制为十页，需要明显压缩教学示例和工程细节；不宜用缩小字号解决内容过载。

## 五、方案三：问题驱动的导师进展报告型

建议标题：**四轻子神经网络研究进展：筛选效果、输入组比较与统计可靠性**。

主线：每章回答一个具体问题，采用“问题 → 必要方法 → 证据 → 有限结论”的一致组织方式。

1. **研究问题与主要发现概览**
   - 1.1 本次报告回答的三个问题
   - 1.2 主要发现、支持证据与解释边界对照
2. **共同背景：这些比较建立在什么基础上？**
   - 2.1 模拟信号、背景与共同选择
   - 2.2 输入组、样本分工与冻结规则
   - 2.3 事件数、产额和 W68 各表示什么
3. **问题一：网络保留了什么、去除了什么？**
   - 3.1 阈值如何确定
   - 3.2 事件数、信号保留率与背景抑制
   - 3.3 绝对质量谱与归一化谱形
4. **问题二：删去输入组后，标称区间怎样变化？**
   - 4.1 双类别推断与比较规则
   - 4.2 五种表示和种子内差值
   - 4.3 哪些方向一致、哪些随种子变化
5. **问题三：这些差异有多稳健？**
   - 5.1 有限 MC 与阈值重估诊断
   - 5.2 model-self 覆盖率结果
   - 5.3 已有证据不能回答的问题
6. **当前结论与下一步优先级**
   - 6.1 已有证据支持的判断
   - 6.2 待核实的样本、筛选和权重问题
   - 6.3 覆盖率研究及暂缓执行的独立评估事项

附录 A：完整数据与方法说明。

附录 B：补充结果、参考文献和溯源。

建议篇幅分配：第 1—6 章约占正文的 10%、15%、30%、20%、15%、10%。第 1 章只作短摘要，不提前堆放完整结果表；每张主要图表只出现一次。

## 七、三套方案都应遵守的排版原则

- 用真正的章节与小节层级组织内容，避免手写编号与大量粗体段落替代结构。
- 减少按旧页面逐一强制换页；按图表阅读需要保留必要分页。不要让“续页”失去明确标题。
- 图表放在首次解释附近，保持“问题说明 → 图表证据 → 解读及限制”的连续顺序。
- 明确区分展示用七个质量箱与推断用单质量箱，明确高分谱展示不意味着丢弃低分类别进行推断。
- 主文保留样本来源、共同选择、权重含义、模型冻结和关键限制；字段字典、详细角度推导、来源逐项比对及修订流水放入附录。
- 不用 AUC、产额保留率或视觉上的峰突出替代区间结果；不把标称区间缩窄写成已确认的精度提升。
- 本文只重新安排已有内容；不引入历史 test05 的数值，不将现有诊断提升为独立验证，不把待执行的 assessment/T2 列为完成结果。

## 推荐

如果仍以当前“事件选择与质量谱”报告为交付目标，优先采用方案一。它保留原题意，集中展示两幅核心图，并把后来加入的统计研究放到明确的辅助位置。

如果目标是统一汇报整个 draft-v2 项目，采用方案三。若要形成系统的研究论文叙述，则采用方案二，并同步重写题目与引言，不能只移动目录。
