## 2. 层 A 的冻结问题与数值方法

问题：在总预期观测约五个、非负信号强度边界存在时，固定 chi-square(1) 临界值的区间覆盖如何随真实 mu 和类别稀疏性变化？

生成模型为各箱独立的 `N_i ~ Poisson(mu*s_i+b_i)`，s、b 为已知固定非负常数。所有情景保持总产额一致：

| 情景 | 信号分配比例 | 背景分配比例 | 用途 |
|---|---|---|---|
| one_bin | 1 | 1 | 单箱低计数参照 |
| two_equal | 0.5 / 0.5 | 0.5 / 0.5 | 不增加信息的分箱恒等检验 |
| two_separating | 0.8 / 0.2 | 0.2 / 0.8 | 具有区分力的合成分类 |
| two_sparse | 0.95 / 0.05 | 0.05 / 0.95 | 稀疏、较强区分的压力情景 |

后三者不是 BC/AC/ABCD 的实测分布。总产额为原审查的舍入值，不宣称与任何实际模板逐字节一致。

冻结配置：[probe.json](../../var/priority3-lowcount-20260923-001/probe.json)。mu 网格为 0–4、步长 0.05，共 81 点；拟合范围 `[0,20]` 与当前实现一致；置信水平为 68%/95%；Poisson 支持尾预算为 `1e-12`。配置和探查脚本在主计算前复制并散列到 preflight，结果不反向修改这些参数。没有从观察到的覆盖反推科学通过容差；该容差仍为未定义。

独立参考采用显式 Poisson 对数似然。单箱 MLE 使用闭式解；双箱利用对数似然凹性，对单调 score 方程二分求解，包括边界最优。分别计算：

1. **渐近似然比接受集合：** `q_mu <= chi2.ppf(CL,1)`。
2. **Neyman 似然比排序参考：** 在每个注入 mu 上，按 q 从小到大累加原始概率至 CL，同一临界值的并列观测一起接受。它属于 Feldman–Cousins 思路的有限网格实现，不做随机化。

每箱观测上限根据最大注入 mu 选择；各箱尾概率之和给出遗漏概率上界。截断后的概率不重新归一化。覆盖存为 `[已枚举接受概率, 已枚举接受概率+尾界]`；浮点误差另以恒等式和独立计算检查，不包括在概率尾界中。

Neyman 接受集合在注册网格达到目标覆盖，是构造的性质及实现一致性检查，不能被当作对同一方法的外部验证。本次没有求连续 mu 上的完整置信带端点，也没有计算 Neyman 区间宽度、Asimov 替代指标或候选精度排名。

生产函数对上界搜索至 20 仍找不到交点的观测返回 `interval_unbounded`。CSV 将接受集合覆盖与“成功返回且覆盖”分开，并保存上界搜索失败概率；不能把搜索上限当作有证明的有限区间端点。

## 5. 层 B：signed-MC 适用性实验设计，未执行

目标：在真实非负产额已知的条件下，检验有限 signed-MC 的重复生成是否被当前 T1 近似充分描述。首先保持阈值固定，隔离统计模型问题。

建议使用可解析的等幅 signed 权重基准。对一个过程/箱，指定真实产额 y>0、总体有效数 K 和总体抵消比 rho：

```
lambda_plus  = K * (1+rho) / (2*rho^2)
lambda_minus = K * (1-rho) / (2*rho^2)
a = y*rho/K
N_plus  ~ Poisson(lambda_plus)
N_minus ~ Poisson(lambda_minus)
Y_hat = a*(N_plus-N_minus)
V_hat = a^2*(N_plus+N_minus)
```

两个计数在该基础构造中独立，所以 `E[Y_hat]=y`、`Var[Y_hat]=y²/K`。这是**明确假设下的合成生成模型**，没有把真实负权来源默认成两个独立 Poisson。固定 y、K 改变 rho 可以保持前两阶矩而改变分布形状，适合检验仅用 y/V 的近似。

建议开发情景为 `K in {20,100}`、`rho in {1,0.5,0.2}`，信号和背景分别生成；K/rho 是总体参数，不能要求每次实现值都刚好通过支持门槛。K=20 故意接近边界，失败应进入计划分母，不能补抽直到通过。

| 路径 | 外层生成/固定项 | 主观测 | 辅助项语义 |
|---|---|---|---|
| T1 内部闭合对照 | 固定一个模板与 tau | 从该模板产生 Poisson | 按当前模型再生 Poisson 辅助观测；只检验模型自身 |
| MC 重复生成适用性 | 独立重生正/负权 MC，得到 Y/V/tau | 从已知物理真值 `mu*s_true+b_true` 产生 Poisson | 把观测到的 MC 压缩为当前拟合所使用的名义辅助项；不要无解释地再额外抽一次 Poisson 辅助数据 |

第二条路径中 tau 的数据依赖性正是要研究的问题，不能把它自动解释为真实独立辅助计数。若采用不同辅助生成设计，必须另列估计目标，避免把有限 MC 波动计算两遍。

后续扩展包括长尾权重、组内正负相关和跨箱相关。相关情景应直接生成物理组的权重向量，并以组净贡献计算方差/协方差，不能对组内正负条目独立重采样。当前 T1 拒绝跨箱协方差的行为应报告为适用域限制，不能偷偷去掉协方差来让模型运行。

每个场景保留支持失败、优化失败、区间上界搜索失败、成功条件覆盖和全计划成功且覆盖；报告偏差、pull 定义及分布、宽度分布和二项区间。边界处不强求高斯 pull。此次没有为层 B 指定最终正式预算或发布通过容差，也没有因层 A 的结果选择有利 signed 情景。

**启动顺序：** 先审定辅助项语义及独立参考、解决数值精度合同，再做少量开发重复估算支持与单次成本。依据预期覆盖精度决定独立验证预算；开发结果不得并入最终验证样本。

## 6. 层 C：阈值选择程序覆盖设计，未执行

目标：测量每次重新生成 calibration/template、重选联合支持阈值之后的程序性能。现有 F2 普通 Toy 固定阈值；现有 T2 固定 template，因此均不等同于本层。

建议先用有已知分数密度的合成过程，例如信号/背景分别为不同的 Beta 密度。初始 signed 标记与分数独立，使净密度及任意阈值两侧真实产额可以解析积分；更复杂的分数依赖 signed 标记作为后续情景。两角色独立生成，身份命名与随机流独立于所有正式 H4l 运行。

每个外层依次执行：

1. 按冻结生成器产生 calibration/template 物理组。
2. 应用版本绑定的联合支持选择规则，保存全部候选及所选阈值。
3. 根据该阈值解析计算真实两类别强度，并独立生成观测。
4. 分别拟合固定模板 T0 参照和待验证 T1，记录支持、选择、拟合及覆盖状态。
5. 以外层为独立重复单位估计全流程覆盖；若每外层多个内层观测，采用组级不确定度，不把内层样本当独立外层。

校准临界值/方法开发、最终验证必须有不同命名空间和独立随机流。固定网络的结论不自动包括重训练；要扩展到完整学习程序，需另外生成训练资源并重复训练。

本层只能先验证合成生成器适用域。要转化为当前 H4l 的证据，还需过程/权重来源、实际分布代表性和独立资源审计。尚未完成的选择后覆盖继续保留 `unvalidated`，不能因 Neyman T0 参照通过而升级。
