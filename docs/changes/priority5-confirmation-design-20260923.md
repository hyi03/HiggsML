## 4. 单一主比较草案：紧凑表示的非劣性

机器可读草案：[confirmation-design.draft.json](../../var/priority45-audit-20260923-001/confirmation-design.draft.json)。它标为 `draft_not_registered, executable=false`，不是现有生产 schema，不允许传给执行器。尚缺的身份、区间方法、科学容差及预算保留为 null，不用虚构数值填充。

| 设计项 | 本次草案决定 | 注册前必须补齐 |
|---|---|---|
| 主问题 | 在同一质量形状和合格覆盖条件下，BC 是否不劣于 ABCD 超过有科学理由的容差？ | 确认论文主张与输入适用性 |
| 候选 | BC 为唯一主紧凑候选；ABCD 为参照；AC 仅探索 | 承认 BC 来自旧探索；冻结 checkpoint 与协议哈希 |
| 信息与基线 | 两者均显式 mass-off，接入优先级 4 的同一 B0 质量似然 | 质量网格、类别支持、nuisance 和修正来源 |
| 首要估计目标 | 固定网络集合的性能；建议 seeds 42–46 等权平均 | 五组确切模型绑定；不按确认结果选最好种子 |
| 主点位 | `mu=1`，一个明确的名义 nuisance 点 | nuisance 数值和目标分布定义；其他点位作适用域诊断 |
| 精度指标 | 观测分布下的期望完整区间长度 `E[U-L]` | 优先级 3 中已验证的区间构造及期望有限性 |
| 效应定义 | `D = mean_seed(E[length_BC] - E[length_ABCD])`，越小越好 | MC、模板和训练随机性所包含／条件固定的范围 |
| 主假设 | `H0: D >= delta`；有效单侧上置信限严格小于 delta 才支持非劣 | delta 的用途／成本依据，不能由已见约 1.3% 优势倒推 |
| 比较错误率与功效 | 建议单侧 alpha=0.025、目标功效 0.90，均为草案 | 冻结最终值、误差模型、预期效应及预算 |
| 区间可靠性 | 先满足逐情景覆盖、失败与无界处理标准 | 冻结覆盖验收容差／置信界规则；不能只看名义 68% |

`68%` 是单个信号强度区间的置信水平；`alpha=0.025` 是候选比较的单侧错误率，它们不是同一个检验。对于离散 confidence belt，不把非整数 Asimov 值上的旧 W68 直接更名为校准后精度。完整长度 `U-L` 也须与历史 W68 的具体定义区分，历史数字原样保留。

该草案的主比较只有一个，不从 105 对比较中再次选赢家。如果 AC 或其他候选也升级为确认主张，须在看新确认值前重新冻结假设族及如 Holm 的多重性规则。非劣不等于优越；若要检验有实际意义的改善，另行预定义最小改善和错误率安排，不根据本次确认结果切换目标。

固定网络结论只涵盖这些模型及明确的目标分布。要声称“BC 学习程序更好”或“更省训练样本”，需要独立外层训练资源、重新训练及全部选择过程；现有 mass-on 样本效率协议不能直接接收 off-only BC。

## 5. 不确定度、物理配对与失败处理

五个网络种子共享 MC，不是五个独立物理样本。对固定五组模型，应先在每个外层物理重复内等权汇总，再由独立外层单位估计不确定度；训练随机性作为另一维报告，不用五种子标准误替代 MC 不确定度。

主估计目标需明确是固定模板条件期望，还是包含有限 calibration/template 估计的程序期望。拟确认流程级稳健性时，后者需要每次外层重新取得 calibration/template、重新选择阈值及建模；内层观测在各外层内生成，不能把内层 Toy 数当独立 MC 批次数。单一 MC 池上的组 bootstrap 可以提供假设条件下的不确定度，但不等于独立物理总体；必须经优先级 3 的已知真值基准检验其用途。

两候选可用同一已授权物理组评估并保留组级相关性。若采用联合分类 Toy，必须先证明每个联合格点的过程率非负、边缘重现和相关结构有效。signed-MC 的边缘通过支持不证明联合格点合法；不裁负、不取绝对值。人工 CRN 只能声明为数值积分耦合，不能解释为物理事件配对。联合模型不成立时可预先注册独立边缘积分，但应另行处理共享模板的估计相关性并限制结论。

完整记录全部计划单位：支持失败、拟合失败、无界／搜索截断区间和正常区间。覆盖至少分别给出成功条件覆盖与全计划“成功且覆盖”比例；后者不是隐瞒失败后的覆盖估计。出现无界区间时，期望长度可能为无穷；不得通过删除或任意截断获得有利均值。失败处理未定义或指标不可估计时，结论为无法确认，不补抽至成功、不事后切换中位数。

## 6. 功效与预算如何确定

先在与确认资源、随机流及预算分离的 development 情景中估计外层差值方差、支持失败概率、区间计算成本和尾部行为。若独立外层差值近似有有限方差，规划近似可写为：

```text
N_outer ≈ (z_(1-alpha) + z_power)^2 * Var(D_outer) / (delta - D_design)^2
```

其中 `D_design < delta` 来自事先有依据的设计情景；不能从旧赢家优势直接估计期望效应。这个式子只用于成本规划，非离散／边界／失败机制下的最终检验保证。实际应在独立合成生成器中检验比较方法的错误率和功效，分开外层 MC 预算与内层积分误差；coverage 的验证预算另按目标精度决定。

目前 delta、外层独立资源量、合适的区间／比较方法和方差都未定，因此不填写貌似精确的正式 Toy 数。预算、失败停止规则、随机流命名空间、是否允许任何序贯规则，均应在打开确认数值前冻结；默认固定预算，禁止按显著性临时延长。
