| High | Correctness / Scientific | `src/higgsml/inference/assessment.py:43-104`; `src/higgsml/inference/likelihood.py:209-218` | **SOL-CR-002 — Joint Toy eligibility is checked after collapsing all backgrounds into one label, contrary to the registered process-wise rule.** | `_joint_mother` builds rates only for labels 0 and 1 (`np.bincount(... * (work.label == label))`), and `paired_event_toys` again samples one total rate per joint cell. A negative signed rate for one background process can therefore be hidden by a positive rate from another background process in the same joint cell. The confirmed sprint rule requires process-wise joint rates to be nonnegative and to reproduce candidate marginals. The added negative-rate test has no `process` column and only makes the entire label-0 aggregate negative, so it does not cover cancellation between background processes. | Build and validate joint intensities separately for every physical process (with the signal scaled by `mu`), then sum independent process draws when projecting candidate observations. Verify every candidate/process marginal against its frozen parent and add a regression fixture where one background process is negative but the aggregate background remains positive. Mark pairing unavailable or fail with the registered support status when a process rate is invalid. |

| Medium | Consistency / Statistics | `src/higgsml/inference/bootstrap.py:63-85`, especially `:78-80`; `src/higgsml/inference/attribution.py:155-167` | **SOL-CR-004 — Event-MC “ranking” intervals target median per-seed rank rather than the registered rank of median W68.** | The primary table orders candidates by each subset's five-seed median W68, and seed resampling correctly ranks resampled median widths. The event bootstrap instead collects each replica's `median_rank`, which is the median of five within-seed ranks. Ranking the median widths and taking the median of ranks are non-equivalent, so the exported event-MC ranking interval can describe a different estimand than the main ranking. The MC-bootstrap test exercises only the all-failed case and cannot detect this. | For each complete event replica, form the 15 five-seed median widths and compute average ranks across those medians; aggregate those replica-level ranks. Validate allowed `(stage, mu)` cells and budgets in `report()` as well as in the outer script. Persist the plan snapshot/receipt in the final report provenance and add rejection tests for wrong plan, family, budget, input ID, and stage/`mu`. |
