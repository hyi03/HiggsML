## 4. checkpoint 的具体修改方案

采用容易审计、无需再调联合指标的默认方案：

1. epoch 使用 one-based 编号。1—5 为 warm-up；6—15 为 ramp；16—200 为完整目标 λ 阶段。
2. 新 adversarial 候选固定训练 200 epoch，最终选 epoch 200。不按历史最高 AUC 恢复模型；非有限 loss、无有效质量箱或未完成训练均记录失败，不退回 warm-up/ramp checkpoint。
3. M2/M3 继续使用现有 AUC 早停默认值，但解释为分类训练选择，不能宣称 μ 最优。种子 42—46 全部报告。
4. 新增 `M3-fixed200` 作为 M6 的 λ=0 配对参照，使用相同初始化、数据顺序、预算与最终 epoch 规则。M3 原始早停结果仍保留；两者不可使用同一 ID。可复用共同训练前缀和已保存状态，但必须得到完整 200 epoch 的 λ=0 模型。
5. 所选 checkpoint 记录 epoch、规则、目标/有效 λ、验证绝对权重 AUC、背景质量依赖指标。诊断可采用固定背景工作点的绝对权重质量 KS 与质量箱接受率，阈值求取/分箱来源由协议声明；不得使用 assessment 来决定 checkpoint。

选择固定轮数消除了本次指出的恢复早期模型问题，但不证明优化已收敛。记录训练曲线和最终状态；优化预算不足可成为负结果。后续若改联合判据，应在新协议中预先定义，不从本次 assessment 反调。

## 5. T2、负权重与新增对照的统一口径

### 5.1 T2 不再是自动叠加的似然误差层

| 标签 | 推断/实验对象 | 具体处理 |
|---|---|---|
| T0 | 固定映射、固定名义模板 | 事件计数涨落的理想模板基准；保留原定义。 |
| T1 | 固定映射、有限 template MC | 所有方法采用同一类经验证的模板统计模型；没有 CDF 的普通分数也属于这一层。 |
| T2-procedure | 重复 calibration 构建分析 | 外层事件组 bootstrap，得到一组重新冻结的分析；每个分析内部执行 T1，流程波动与内层区间宽度分别报告，不将外层散布再次添加为 nuisance。 |
| S / P | 人为压力 / 有来源的物理变化 | 固定观察量定义下建模响应；明确是否进入拟合。保持原有证据层次。 |

外层副本 r 的顺序固定为：重采样 calibration → 重估 CDF 或普通分数阈值 → 冻结 `mapping_id=r` → 对独立 template 事件和共同伪事件应用同一映射 → 重建模板及观测计数 → 拟合。普通分数阈值与 CDF 均执行此流程。

外层默认固定训练模型和 template/assessment 母事件，用以隔离校准构建波动；若另行重采样 template、assessment 或重训网络，必须明确扩展的随机化范围，并在方法间按物理事件组配对。对内层 toy 覆盖，分别声明模板辅助测量是固定还是重生成，以及生成模型；不能把只重采样 calibration 的结果称为涵盖全部 MC 不确定性的无条件覆盖。

固定映射不保证没有校准相关失配。如果后续直接用“CDF 后背景均匀”替代独立模板，或通过 CDF 预测接受率，需将其作为新的预测模型，传播校准误差和残余非均匀性。若模板/数据存在有来源的响应差异，也需在固定观察量下建模；这不同于人为更换类别定义。

### 5.2 有限 signed MC：确定模型候选和冻结门

对每个物理过程、质量箱及分数类别至少记录原始事件组数、正/负权重和、`sum|w|`、`sumw²`、signed yield，以及：

- `N_eff_signed = (sum w)^2 / sumw²`：有符号产额的相对精度诊断。
- `N_eff_abs = (sum |w|)^2 / sumw²`：绝对权重分布的统计诊断。
- `rho = |sum w| / sum |w|`：抵消程度；仅适用于非零分母，未定义时明确报状态。

这些量不能替代完整模型。如果多个相关技术行属于同一事件，方差和 bootstrap 按事件组处理；不能无条件把逐行平方和当成独立抽样方差。

**建议先导 T1 的首选候选**为每个过程/箱独立的 `shapesys` 有效计数近似：以正名义产额 y 和绝对标准差 σ 构造非负乘性尺度 γ，有效计数 τ=(y/σ)²，辅助 Poisson 约束以 τγ 为期望。仅在相应事件独立性、相关性假设及有限统计近似经验证时使用。不同过程/箱的参数命名和相关性必须显式冻结；“所有方法一致”指模型规则一致，方法差值的配对来自共同事件，不能靠共享 modifier 名称制造跨方法相关性。

`staterror` 的正态辅助约束和按通道/箱组合样本误差的结构不能视为 `shapesys` 的同义写法；`histosys` 形状响应也不是 signed MC 统计问题的通用替代。协议需核验所锁定 pyhf 版本的实现、参数界限、零值行为及辅助观测构造。

强抵消、小有效计数、非正产额或相关性不满足假设时，不凭 τ 和 sumw² 宣称近似成立。依冻结规则共同合箱；仍失败则报告 `insufficient_statistics` 或 `template_stat_model_unvalidated`。更细的正负贡献生成模型属于单独设计，需保持物理期望非负，不能把负权重事件作为负 Poisson 率。阈值数值和合箱顺序在统计审计后、assessment 前冻结。

| M5-abs | M3 冻结分数＋绝对权重条件 CDF | 与 M5 及 M6 构成 Q3 的必要目标分布桥接。 |
| L1 | decay7＋pt4l＋y4l＋m4l，普通 MLP＋物理 CDF | 提前检查整体运动学/表示解释；先导小规模，独立命名。 |

M5-abs 只改变 CDF 的目标权重，最终物理模板仍用 signed 权重。该对照可识别目标分布差异的影响，但不会单独消除优化目标、容量或分箱等其他差异。

M0c 的改善属于质量分析优化，不是新增角/产生信息。物理 Shapley 的原始分数实验族设 `v(∅)=-W68(M0c)`；另列 M0c−M0 和完整方法−M0，避免把外部基线差计入各特征组。

CDF 实验族若用于 Shapley，空集也须经过同样 CDF 流程。精确固定 m 时，mass-only 分数 t=f(m) 为点质量，连续严格单调 CDF 假设不成立，不能强求两个非空等产额类别。需预注册 ties、平台及结构零箱规则，不得通过事件身份或标签分组制造信息；共同支持上同时为结构零的观测箱可按规则省略。有限质量切片可能仍保留箱内质量排序，须纳入分箱敏感性解释。如果协议无法定义有效的空集，暂停该 CDF 族精确 Shapley，不能替换成原分数 M0c 或把它置零。该问题不阻止先导主比较。

## 6. 主比较、种子与覆盖率的精确定义

建议下一版方案直接采用以下口径，避免将 Asimov 区间与 toy 中位数都称为“预期宽度”：

- 主比较：M5（engineered19＋物理 CDF）对 M4（decay7＋物理 CDF），同一事件角色、质量边界、两分数类别、CDF 估计/合并规则与 T1 模板统计模型。
- 注入点：μ_true=1；名义亮度沿用 10 fb⁻¹。Asimov 事件期望及辅助观测均按该 T1 名义模型构造，并绑定来源。
- 主量：`W68_Asimov = μ_upper − μ_lower`，μ≥0；区间构造、边界约定及求根失败处理在协议声明。95% 宽度、toy 中位宽度、T0 及 S/P 为辅助量，分别命名。
- 每个网络种子 s∈{42,43,44,45,46} 计算配对改善 `R_s = 1 − W68_Asimov(M5,s)/W68_Asimov(M4,s)`；预先以五个 R_s 的中位数作主汇总，同时列全部值。任何失败或无定义分母均保留，不能删掉失败种子后沿用原主汇总声明。
- 种子离散反映训练随机性，不是 MC 抽样置信区间；方法差值的不确定性需配对事件重采样并声明重建范围。
- 先导覆盖检查沿用 seed42，μ_true=0、1、2 各 500 次，各方法共享物理伪事件。按自模型闭合、独立 assessment 母模板、外部失配分别标识，不能把来源混为一种覆盖。
- 物理 Shapley 主价值函数采用同一 μ=1、T1、Asimov W68；逐种子计算 Shapley 及效率恒等式，再汇总。逐组中位数一般不保持效率恒等式，不拿中位数表强行检验加和关系。

500 次独立条件 toys 下，覆盖率估计标准误差为 `sqrt(p(1−p)/500)`：p=0.68 时约 2.09 个百分点，p=0.95 时约 0.97 个百分点。正态近似双侧 95% 半宽约 4.1 和 1.9 个百分点；正式表格报告二项区间，不将近似半宽等同于既定功效下的最小可检出差异。

方法间覆盖差使用配对成功/失败指标的联合结果估计误差；共同母模板的不确定性另列。增加 toys 只缩小条件 Monte Carlo 抽样误差，不能补足母模板缺失的背景尾部、组分或相空间。T2-procedure 的外层/内层预算单独预注册，不将“500 次”默认解释成每个外层再运行 500 次的无限扩张预算。

## 7. 分阶段有效统计门与修改顺序

以文档快照作算术示意：背景 template 约 5,216×20%=1,043，assessment 约 522；35×2 个格子的未筛选平均分别约 14.9 和 7.5 个事件。这不代表筛选 2e2μ 后的数目、每个格子的实际统计或有效样本量。

不能在没有分数前声称已审计全部二维模板，因此采用两级门：

| 顺序 | 修改/推进动作 | 通过条件与证据 |
|---|---|---|
| A | 先修订 §2、§6.1、§7.2、§7.4、§8.2 的统计定义 | 主比较、checkpoint、T2、空集和指标语义一致；仍标记协议待冻结。 |
| B：P0/P1 | 输入和终态导出后，审计角色、质量支持域、产额、负权重与有效统计 | 仅使用角色契约允许的信息；冻结数值门槛、合箱算法和预定网格。原始支持不足时停止后续模型展开。 |
| C：最小 P2/P3/P4 | 先用 seed42 的 M0c、M2/M3 分数及 CDF 建立关键模板/CDF；MELA 参考就绪后检查 M1/M1c | 依据 calibration/template 的允许统计检查条件分布、两类别、共同合箱和 T1 近似；禁止用 assessment 的拟合结果或方法胜负选择分箱。 |
| D | 门 C 通过后冻结候选扩展及评估规则，展开其余种子、λ、桥接与 L1 | 新候选若触发统计失败，按既定规则报状态；如需全局分箱变更，必须在 assessment 前重新冻结并一致重建相关方法。 |
| E | 一次性执行冻结先导的 assessment 评估 | 结果包括负结果、统计不足、拟合失败与覆盖限制；评估后修订作为新探索版本，不重称独立确认。 |
| F | 依据先导设计完整归因、更多 bootstrap 与外部验证 | 完整 15 组合、四动量、大规模重采样可延后；Q3 尚缺桥接或 MELA 尚未验证时，相应比较保持未完成。 |

assessment 的实际支持不足可在冻结评估时导致先导受限，不能靠看到它后重划角色补救。若只用身份/预声明粗统计作容量规划，也须记录该角色已被使用的范围；不能再声称其完全未参与分析设计。

lab-extension 应在 C 门后进入先导解释，采用固定小规模种子预算并与同种子的 M4/M5 配对。它有助于区分整体运动学与工程冗余，但接受度和产生模型依赖仍需后续有来源变化验证。y4l 重建不可靠时记录缺失，不从现有 19 列猜造。
