## 5. Verified correct (static audit, no finding)

The following were checked line-by-line against the protocol and found faithful:

- **§3 selection**: 19-stage order and names; per-lepton stage survivor-count ≥ 4 before `exactly_four_good_leptons` (== 4); trigger `bool(trigE) or bool(trigM)`; type ∈ {11, 13}; tight ID; `pt > 0` and iso/pt < 0.3 (strict); e/mu d0sig 5.0/3.0 (strict); `|z0/cosh(eta)| < 0.5`; ≥ 1 trig-matched; stable pt-descending sort (`np.argsort(-pt, kind="stable")`); pt thresholds 20/15/10/7 (`>=`); eta 2.47/2.7 (strict); integer charge sum == 0; SFOS pairing; all-SFOS masses strictly > 5; Z1 (50, 106) and Z2 (12, 115) strict windows; `105 <= m4l < 160`.
- **§4 reconstruction/Base14/Angular5**: `(E, px, py, pz)` from pt/eta/phi/e; `m = sqrt(max(0, E² − p²))`; the three index partitions; in-partition Z1 = closer to 91.1876 with ties → first pair; multi-partition `min((distance, z1_tuple, z2_tuple))`; `delta_phi = (a−b+π) mod 2π − π` ∈ [−π, π); `deltaR = hypot(dη, dφ)`; `deltaPhi_ZZ = |δφ|`; boost formula with identity at β=0 and failures at |β|≥1/zero-energy/non-finite; cosine clip at 1e-12; charge-ordered decay orientation; `n1`, `n2`, `nprod`; all five Angular5 formulas and ranges; degenerate geometry raises (→ exit 3 via the pipeline).
- **§5 weights/identity/split**: `physical_weight = L·xsec·k·filteff/sumOfWeights·mcWeight` with zero/non-finite failures; Higgs per-event constants checked constant with `rtol=1e-12, atol=0`; ZZ fixed constants; per-sample `train_weight = |w| / mean(|w|)` after selection, before merge, with the mean-0 → 1.0 rule; identity `(source_sample, source_entry)` with cross-chunk continuity and global uniqueness check; BLAKE2b(8, big-endian) % 10 → 6/2/2 split buckets.
- **§6 serialization**: exact 29-column order (checked-in YAML matches §6.1, incl. exclusion of the five legacy normalization columns); higgs-then-zz row order with strictly increasing `source_entry`; LF-only CSV with trailing LF; `.17g` tokens with `-0` → `0`; base-10 integers for the five integer columns; enum-only strings; `gzip.compress(…, compresslevel=9, mtime=0)`; both gzip and canonical-content SHA-256 recorded (probe: cross-run gzip bytes identical).
- **§2 binding/CLI**: run-config whitelist (exact keys, `path`-only samples, positive-int chunk, duplicate-YAML-key rejection); SHA-256 verify before read and re-verify before publication; `channelNumber == DSID` enforcement; DSID 700600/`zz.root` rejected via pinned-hash mismatch (fail-closed exit 3, verified by the integration test); no `entry-stop`/sample/profile/selection overrides; `--run-dir` under `neural/runs` with no-overwrite transaction; exit codes 0/2/3/4/70 as declared; MC-only boundary enforced (`test_package_contract.py`: no `xgboost` imports; only the two pinned samples can ever be read).
- **§8 artifacts**: `cutflow.json` matches §8.1 exactly (19 ordered stages, higgs→zz sample order, `z2_min_mode: fixed`, count/efficiency/signed/absolute fields; `m4l_analysis_window == selected` counts, probe-verified); manifest published last; manifest lists `config.yaml`, table, cutflow, `mc_summary.json`, excluding itself; inputs carry all §8.3 input fields; `configuration`, `determinism`, `platform`, `software.python/git_commit/git_dirty` present.

## 8. Conclusion

The rewrite achieves the intended separation of concerns (thin CLI → application service → domain/preprocessing/artifacts), transcribes the §3–§6 scientific formulas faithfully, and gets canonical serialization, transactional publication, and MC-only fail-closed binding broadly right. The blocking issues before sprint completion are: enforce fail-closed behavior for non-finite/schema-bad events (F-01, F-02), complete the protocol loader's binding of the frozen contract (F-03, F-08, F-10), restore the frozen artifact-schema fields (F-04, F-09, F-07), implement the §7 gate runner (F-05), and close the §9 test-coverage gap (F-06, F-11). None of the findings require relaxing any predeclared rule; all fixes are tightening/documentation work. The authoritative locked `osx-arm64` full-data gate remains unexecuted and must stay recorded as `authoritative_gate_not_run`.
