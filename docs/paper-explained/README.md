# 中英文双语论文讲解 · 33 页

直接打开 [中文版](index.html) 或 [English edition](index-en.html)，建议使用现代 Chrome 或 Edge。两版统一放在本目录，顶部语言入口切换时保留页码；英文使用说明见 [README-en.md](README-en.md)。无需安装依赖、启动服务或联网。保留本目录内全部文件；如需打开论文源码和原图链接，也保留它在仓库中的相对位置。

正文采用中文，英文术语用于对照论文。桌面以 16:9 演示，窄屏转为纵向阅读。每页的“详细讲解”默认展开，含推导、术语、补充限制及自测。本版在原 30 页基础上增加两页 μ 与区间入门，以及一页 Shapley 两组演算，共 33 页。

## 操作

- 左右方向键、PageUp/PageDown 或下方按钮翻页；Home/End 到首尾页。
- 页码输入、目录与 `#slide-24` 等地址可直接定位；浏览器前进/后退保留页码历史。
- 控件获得焦点时，方向键保留给控件；按 Tab 可遍历按钮与互动。
- “详细讲解”默认在当前页和翻页按钮下展开；可手动收起，翻页保留当前展开状态，刷新后恢复默认展开。“全屏”使用浏览器全屏 API。
- “打印”输出全部 33 页，每张一页，默认不打印详细讲解。推荐浏览器“另存为 PDF”，关闭浏览器页眉页脚，使用 CSS 定义的 16:9 页面。
- 互动状态保留于当前页面会话。刷新恢复默认示例；没有账号、远程请求、追踪或持久化存储。
- 中英文切换保留当前页码；控件选择恢复该语言页面的默认值，详细讲解恢复默认展开。

## 内容路线

第 1 页研究问题；2–3 页串联“μ → 区间 → 宽度 → 比较依据”；第 4 页全流程；5–8 页模拟与处理；9–11 页特征组合；12–15 页网络；16–18 页类别；19–22 页似然与区间；23–24 页排序与配对；25–27 页 Shapley 入门、四组定义与真实演算；第 28 页条件交互；29–32 页验证；33 页回顾、术语与来源。

第 12、21、23、24、27、28 页提供教学互动。第 2–3 页的计数表与区间为各自独立的手工概念例子；第 21 页是手工 T0 示例，不执行论文 T1 拟合；第 25 页用两个组的手工宽度例子解释 Shapley，随后推广到论文四组。神经网络图是结构示意，不是权重可视化。所有真实数值只来自选定汇总包。

## 维护与核对

`content.js` 保存讲解与论文对应关系，`visuals.js` 保存图示，`widgets.js` 保存互动，`math.js` 保存纯教学计算，`app.js` 保存导航。`data.js` 是为网页发布保留的精选汇总投影，不包含事件、模型权重或完整运行档案。

`en/` 保存英文正文、图示文字、控件与导航，`index-en.html` 是英文入口。两版共用根目录的 `data.js`、`math.js` 和基础 CSS，因此数值与数学计算只有一份；英文 CSS 只调整排版。

只有明确刷新教学数据时才运行导出；导出器调用现有 `load_snapshot()`，强制校验选定结果/来源 SHA-256 和报告身份，不允许切换到同名的不同报告。普通阅读不需要本地快照。

```powershell
& 'D:\apps\anaconda3\Scripts\conda.exe' run -n pytorch python docs/paper-explained/tools/export_data.py --check
node docs/paper-explained/tools/check.mjs
```

省略 `--check` 才会更新 `data.js`。Node 检查将网页计算与保存的 Shapley、24 个条件交互和 105 个配对结果对照；这些是发布内容与数学一致性检查，不是新的科学验证。

新增文件全部使用 LF。教学修改不触发下载、训练、似然重拟合、Toy 或 assessment 访问，不更新论文选择、原图与冻结协议。

具体检查范围与环境限制见 [VERIFICATION.md](VERIFICATION.md)。已逐页检查桌面与窄屏显示及全部互动；自动化浏览器不允许 `file://` 导航，因此双击离线打开和系统打印预览未由该环境直接核验。
